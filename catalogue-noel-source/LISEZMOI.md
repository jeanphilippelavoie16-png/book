# Catalogue des Souhaits

L'app de Noël des enfants : un catalogue qu'on feuillette au doigt et où on entoure au crayon.

- `catalogue-noel/` : l'app publiée par GitHub Pages (page, planches d'images, icônes, mode hors ligne).
- `catalogue-noel-source/` : `gabarit.html` (l'interface), `produits.json` (les 671 jouets), `construire.py`.

Modifier en ligne sur GitHub (crayon sur le fichier, ou touche « . » pour l'éditeur complet),
puis enregistrer (« Commit changes ») sur `main` : le déploiement reconstruit l'app et la publie.

- Changer un prix, un nom, un lien : `produits.json`.
- Retirer un jouet : effacer son bloc `{ … }` dans `produits.json`.
- Changer un texte de l'accueil ou l'interface : `gabarit.html`.
- Ajouter un jouet demande sa photo dans les planches : ça se fait avec Claude.

## Sur l'iPad

1. Ouvrir l'adresse Pages dans Safari.
2. Bouton Partager → « Sur l'écran d'accueil ».
3. L'app s'ouvre ensuite en plein écran, sans barre de Safari, et marche sans réseau.

Les ronds et les super cœurs restent dans l'iPad (une liste par appareil).
