# Vocabulaire de l'index — Le Grand Livre du Chalet
#
# Ce fichier dit QUOI indexer et COMMENT le reconnaître. Le script index/outils/construire-index.py
# trouve OÙ (les ancres) et écrit index/tome-N.json et index/general.json.
#
# Une entrée par ligne, cinq champs séparés par « | » :
#   Terme affiché [Nom latin] | motifs | voir aussi | chapitres forts | tomes
#
# - Terme affiché : le nom courant québécois. Le nom latin entre crochets, seulement s'il est au
#   glossaire (plan/glossaire.md) ; l'index l'imprime entre parenthèses, en italique.
# - Motifs : expressions régulières, séparées par « ; », appliquées au texte en minuscules SANS
#   ACCENTS (é -> e, œ -> oe, apostrophe droite). Un motif qui commence par « ~ » s'applique au
#   texte en minuscules AVEC accents (utile pour maïs / mais).
# - Voir aussi : autres termes de ce fichier (sans le nom latin), séparés par « ; ».
# - Chapitres forts : numéros, séparés par « , », le premier étant celui qui porte le sujet.
#   Ils passent devant, et une mention plus courte y suffit.
# - Tomes : restreint l'entrée à ces tomes (quand le mot change de sens d'un tome à l'autre).
#
# Renvoi pur (sans ancre) :   Terme -> Cible ; Autre cible
#
# Pas de mot trop courant (« eau », « bois » seuls). Au plus six ancres par entrée : le script
# garde les plus utiles.
