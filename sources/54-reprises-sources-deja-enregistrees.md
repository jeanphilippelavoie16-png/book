## Règle appliquée

Quand une valeur vient d'un de ces fichiers, le chapitre 54 cite l'organisme entre parenthèses
exactement comme s'il l'avait captée lui-même, et le chiffre est vérifiable dans le fichier
nommé ci-dessus. Quand deux fichiers du dossier donnent la même valeur, c'est noté.
